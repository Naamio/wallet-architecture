# Naamio Wallet — architecture

Architecture decision records, protocol specifications, and design documents for [Naamio Wallet](https://naamio.dev).

Naamio Wallet is an open source credential engine providing encrypted credential storage, verifiable credential protocols, and on-device intelligence for anticipatory credential presentation.

## Milestone track

Codenames drawn from historic currencies — from the first shell traded between strangers to the coin that reached every shore.

| Milestone | Focus | Due |
|---|---|---|
| Cowrie — Credential foundations | OTP management, credential storage engine, basic credential model, reference Android application | 2026-06-30 |
| Solidus — Credential protocols | OpenID4VCI/VP, SD-JWT VC, W3C VC Data Model 2.0, credential lifecycle management | 2026-09-30 |
| Sterling — Standards compliance | EUDI Architecture Reference Framework, ISO 18013-5 mdoc, SIOPv2, conformance test suite | 2026-12-31 |
| Tally — Authentication | FIDO2/WebAuthn passkeys, Credential Exchange Protocol, biometric binding | 2027-03-31 |
| Ducat — Anticipatory intelligence | On-device inference engine, context-aware credential selection, open service discovery | 2027-06-30 |
| Thaler — Automotive identity | CCC Digital Key 3.0/4.0, ISO 15118 Plug and Charge, ISO 23220 mobile identity | 2027-09-30 |
| Florin — Delegation and sharing | Policy-controlled credential sharing, time-limited access, trusted delegates | 2027-12-31 |
| Crown — Security hardening | Post-quantum readiness, zero-knowledge selective disclosure, offline BLE/NFC | 2028-03-31 |
| Guinea — Platform breadth | iOS, desktop, wearable, embedded, vehicle runtime | 2028-06-30 |

## Structure

This repository contains architecture decision records and protocol specifications. Implementation repositories will be created as development begins.
