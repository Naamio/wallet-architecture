# Naamio Wallet — Architecture

Architecture decision records, protocol specifications, and design documents for [Naamio Wallet](https://naamio.dev).

Naamio Wallet is an open source credential engine providing encrypted credential storage, verifiable credential protocols, and on-device intelligence for anticipatory credential presentation.

## Structure

This repository contains architecture decision records and protocol specifications. Implementation repositories will be created as development begins.
